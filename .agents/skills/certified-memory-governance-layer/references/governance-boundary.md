# Governance boundary

CMGL assesses procedural admissibility under supplied policies, scope, authority evidence,
receipts, and ledger checks. It does not decide truth. Missing or unsafe external record status is
downgraded before filtering unless an explicit trusted-results setting is chosen. Retain stale,
superseded, tombstoned, contradicted, quarantined, contaminated, expired, and unauthorized states
as typed residual information rather than silently normalizing them away.
